高中解析几何 · 直线与圆的位置关系

圆 $x^{2}+y^{2}=4$ 上到直线 $l:\;y=x+b$ 距离为 1 的点，可能是 0 / 1 / 2 / 3 / 4 个

解题过程

设圆心 $O(0,\,0)$，半径 $r=2$；把 $l$ 写成一般式 $x-y+b=0$。

1

点 $P(x,\,y)$ 到 $l$ 的距离为 1：

$$\frac{|x-y+b|}{\sqrt2}=1\quad\Longrightarrow\quad x-y+b=\pm\sqrt2$$

即两条平行线 $l_1:\;y=x+b-\sqrt2$ 与 $l_2:\;y=x+b+\sqrt2$。

二者到 $l$ 的距离都是 $\frac{\sqrt2}{\sqrt2}=1$（斜率都是 1，沿 $y$ 轴平移 $\sqrt2$）。

2

原命题 $\iff$ 这两条直线与圆 $C$ 的公共点总数恰为 3。

两条平行线各自与圆最多交 2 点，故总数 3 只能是 一条相切（1 点）$+$ 一条相交（2 点）。

3

设圆心 $O$ 到 $l$ 的距离 $d=\frac{|b|}{\sqrt2}$。两条平行线分别位于 $l$ 的两侧，它们到 $O$ 的距离是 $|d-1|$ 和 $d+1$。

① 若「远侧」相切：$d+1=2\Rightarrow d=1$。此时近侧距离 $|1-1|=0<2$，恰与圆交于 2 点，合计 3 点，符合。

② 若「近侧」相切：$|d-1|=2\Rightarrow d=3$。此时远侧距离 $4>2$ 无交点，合计只有 1 点，舍去。

判断依据：直线到圆心的距离 $h$ 与 $r=2$ 比较，$h<2$ 交 2 点，$h=2$ 相切 1 点，$h>2$ 无交点。

4

由 $d=\frac{|b|}{\sqrt2}=1$，得 $|b|=\sqrt2$，即 $b=\pm\sqrt2$。

验证 $b=\sqrt2$：$l_1:\;y=x$ 过圆心，与圆交于 $\left(\sqrt2,\,\sqrt2\right)$、$\left(-\sqrt2,\,-\sqrt2\right)$；$l_2:\;y=x+2\sqrt2$ 与圆相切于 $\left(-\sqrt2,\,\sqrt2\right)$。三点到 $l$ 的距离均为 1 ✓

答案 $b=\textcolor{#b91c1c}{\sqrt2}\quad\text{或}\quad b=\textcolor{#b91c1c}{-\sqrt2}$

五种情形的完整分类

记 $d=\frac{|b|}{\sqrt2}$，两条平行线到圆心的距离为 $|d-1|$（近侧）与 $d+1$（远侧）。每条线与圆：距离 $<2$ 交 2 点，$=2$ 相切 1 点，$>2$ 无交点。把两边的点数相加即可。

4个点
$0\le|b|<\sqrt2$

此时 $d<1$，两条平行线到圆心都不到 2，都与圆相交，各 2 点。
$b=0$ 时两条线到圆心距离都是 1，最对称。

3个点
$|b|=\sqrt2$

此时 $d=1$：近侧线恰好过圆心（直径，2 点），远侧线恰好相切（1 点）。
这就是本题所求。

2个点
$\sqrt2<|b|<3\sqrt2$

此时 $1<d<3$：近侧线仍与圆相交（2 点），远侧线已完全移到圆外（0 点）。

1个点
$|b|=3\sqrt2$

此时 $d=3$：近侧线恰好与圆相切（1 点），远侧线距离 4 已在圆外（0 点）。$|b|=3\sqrt2\approx4.243$。

0个点
$|b|>3\sqrt2$

此时 $d>3$：连近侧线到圆心的距离都已超过 2，两条线都在圆外，圆上没有任何点满足条件。

要点 点数只会在 $0\to1\to2\to3\to4$ 之间切换，且 1 个点和 3 个点都只出现在 $|b|$ 的两个临界值上

推广：半径 $r$ 为任意值时的通用结论

把 $r=2$ 换成一般的 $r$，推理方式与结论形式完全不变，变的只是两个临界值。记圆心 $O$ 到 $l$ 的距离为 $d$，则两条「到 $l$ 距离为 1」的平行线到 $O$ 的距离分别是 $|d-1|$（近侧）与 $d+1$（远侧）。

第一步 · 单条直线

一条直线到圆心的距离为 $h$ 时：$h<r$ 交 2 点，$h=r$ 相切 1 点，$h>r$ 交 0 点。所以只需判断 $d+1$ 与 $|d-1|$ 各自落在 $r$ 的哪一侧，再把点数相加。

$d$ 的范围 远侧线（距 $d+1$） 近侧线（距 $|d-1|$） 圆上点数
$0\le d<r-1$ $d+1<r$ → 2 点 $<r$ → 2 点 4
$d=r-1$ 恰好与圆相切 → 1 点 $|r-2|<r$ → 2 点 3
$r-1<d<r+1$ $>r$ → 0 点 $<r$ → 2 点 2
$d=r+1$ $>r$ → 0 点 恰好与圆相切 → 1 点 1
$d>r+1$ $>r$ → 0 点 $>r$ → 0 点 0

统一判据：点数只在「两条平行线中恰有一条与圆相切」的瞬间跳变，也就是

$d\pm1=r\;\iff\;d=r-1\ \text{或}\ d=r+1\;\iff\;|d-r|=1$

两个临界值之间恒为 2 个点；再往圆心收（$d<r-1$）为 4 个点；再往外推（$d>r+1$）为 0 个点。点数随 $d$ 单向递减：$4\to3\to2\to1\to0$，绝不会跳着来。

第二步 · 带回本题

$r=2\;\Rightarrow$ 两个临界值 $d=1$ 与 $d=3$；又 $d=\frac{|b|}{\sqrt2}$，故 $|b|=\sqrt2$（3 点）与 $|b|=3\sqrt2\approx4.243$（1 点）。本题要求的正是前者。

若把「距离为 1」换成一般的 $a$，只需把上表里的 1 全部换成 $a$：临界值变成 $d=r\pm a$，于是「恰有 3 个点」$\iff d=r-a$（要求 $r>a$，否则近侧线不可能与圆交出 2 点）。

一句话结论 $d<r-1$ → 4 点　│　$d=r-1$ → 3 点　│　$r-1<d<r+1$ → 2 点　│　$d=r+1$ → 1 点　│　$d>r+1$ → 0 点
